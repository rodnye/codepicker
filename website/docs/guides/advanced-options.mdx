# Advanced Options

Codepicker offers a variety of advanced options to adapt its behavior to the specific needs of your project and workflow.

## Glob Patterns

Codepicker uses [fast-glob](https://github.com/mrmlnc/fast-glob) for file searching. You can use advanced patterns:

```bash
# Multiple extensions
codep "src/**.{ts,tsx,astro}"

# Exclude directories
codep "src/**/*.ts" "!src/**/*.test.ts"

# Root files
codep "package.json" "tsconfig.json"
```

## Ignoring Files

By default, Codepicker respects:

- `.gitignore`
- `.codeignore` (Codepicker specific file)
- `.ignore`
- Internal patterns (node_modules, .git, etc.)

You can disable any of these behaviors:

```bash
# Ignore .gitignore (useful for extracting build files)
codep "dist/**/*.js" --no-gitignore --no-default-patterns
```

## Remote Repositories

You don't need to clone a repository to extract its code. Codepicker can read directly from GitHub, GitLab, etc.:

```bash
codep "src/**/*.ts" --remote https://github.com/rodnye/wa-catalog --remote-branch main
```

This is extremely useful for:

- Analyzing open-source projects.
- Giving an LLM context about an external library.
- Comparing code between different branches or repositories.

## Instant Backups

You can use Codepicker as a quick backup tool for your current code:

```bash
# Save current state
codep "src/**" > backup.md

# Restore at any time
codep apply backup.md
```

## Editor Integration

Although Codepicker is a CLI, you can integrate it into your favorite editor via keyboard shortcuts or custom tasks.

### VS Code (tasks.json)

You can configure tasks in `.vscode/tasks.json` to run Codepicker quickly:

```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Codepicker: Copy Context",
      "type": "shell",
      "command": "codep -cD \"src/**/*.ts\"",
      "group": "none",
      "presentation": {
        "reveal": "silent"
      }
    }
  ]
}
```

# Getting Started

Installing and setting up Codepicker is extremely simple. Follow these steps to start optimizing your workflow with LLMs.

## Prerequisites

- [Node.js](https://nodejs.org/) version 18 or higher.
- A package manager like `npm`, `yarn`, or `pnpm`.

## Installation

You can install Codepicker globally to make it available in any project:

```bash
npm install -g codepicker-tool
```

### Verify Installation

Once installed, verify that everything works correctly by checking the version:

```bash
codepicker --version
# or using the short alias
codep --version
```

:::tip Short Alias
`codep` is simply a shorter alias for `codepicker`. You can use it to save time when typing commands.
:::

## Your First Use

Let's extract the context of some TypeScript files from your project and copy them to the clipboard:

```bash
codep -c "src/**.ts"
```

This will search for all `.ts` files in the `src` folder, convert them to the Codepick format, and copy them to your clipboard. Now you just have to paste them into your favorite LLM and start working.

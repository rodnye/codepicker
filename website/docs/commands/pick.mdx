# Pick Command

The `pick` command (which is the default command) extracts the content of your files and converts it to structured Markdown.

## Basic Syntax

```bash
codepicker pick [options] <patterns...>
```

:::note Default Command
The `pick` subcommand is optional. You can simply use:

```bash
codepicker [options] <patterns...>
```

:::

## Available Options

| Option                       | Description                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `<patterns...>`              | **Required**. [Glob patterns](https://github.com/micromatch/picomatch#globbing-features) to search for files. |
| `-c, --clipboard`            | Copies the output directly to the clipboard.                                                                  |
| `-D, --include-docs`         | Adds the Codepick format documentation at the end (useful for LLMs).                                          |
| `-a, --absolute`             | Uses absolute paths instead of relative ones.                                                                 |
| `-l, --lines <n>`            | Limits the number of lines per file.                                                                          |
| `-p, --paths`                | Shows only the file paths, without content.                                                                   |
| `--include-line-numbers`     | Adds line numbers at the beginning of each line.                                                              |
| `--no-gitignore`             | Ignores `.gitignore` rules.                                                                                   |
| `--no-codeignore`            | Ignores `.codeignore` rules.                                                                                  |
| `--no-default-patterns`      | Ignores default patterns (node_modules, .git, etc.).                                                          |
| `--remote <url>`             | Reads code from a remote repository.                                                                          |
| `--remote-branch <checkout>` | Specifies a branch, tag, or commit from the remote repository.                                                |

## Practical Examples

### Copy to Clipboard

Extract all React files and copy them to the clipboard:

```bash
codep -c "src/**/*.tsx"
```

### Include Documentation for the LLM

If you notice the LLM doesn't respect the output format, include the format documentation:

```bash
codep -cD "src/services/**/*.ts"
```

### List Paths Only

Useful for feeding other tools like `xargs` or `grep`:

```bash
codep "src/**/*.ts" -p -a
```

### Limit Lines

For very large files where you only need to see the structure:

```bash
codep "src/**/*.ts" -l 50
```

### Remote Repositories

Extract code directly from a GitHub repository without cloning it manually:

```bash
codep "src/**/*.ts" --remote https://github.com/rodnye/codepicker --remote-branch main
```
